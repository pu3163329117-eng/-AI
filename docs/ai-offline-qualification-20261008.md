# AI 反馈离线稳定性验收

日期：2026-10-08。本轮完成异常反馈修复、可重复的大批量离线验收和前后端回归。所有压力场景使用合成输入与内存模拟响应，不调用 DeepSeek、不读取实际学生理由、不生成正式能力等级。通过结果证明已测软件边界，不证明模型语义质量或真实服务吞吐能力。

## 修复

1. 原先低置信度评价会先清除匹配量表项与误解代码，再检查重复值，导致重复引用被掩盖。现在先校验原始候选的重复引用，再进行置信度降级；诊断的重复观察 ID 也按同一顺序处理。
2. 原先 `UNSCORABLE` 仍可携带 `RETRY_REASONING` 建议。现在无法评分结果必须使用 `HUMAN_REVIEW`，不将弃答呈现为已得到判断。非法候选最多修复一次，最终失败返回不可评分模板。

针对上述问题，修复前的回归有 5 项失败，修复后通过。另保留非法 Unicode 输入调用前拒绝、离线记录比较拒绝低置信重复引用等回归。没有修改提示、试用量表、分数阈值、数据库模型或训练命令。

## 大批量验收

新增 `backend/scripts/ai_offline_qualification.py`，只使用明确构造的 `FakeProvider`，没有真实模型入口。轮数限制为 1 至 10，默认 3；每轮是同一批确定性场景的重复稳定性检查，不是新生成的教研样本。

| 范围 | 本次结果 | 口径 |
| --- | --- | --- |
| 反馈异常矩阵 | 12,180 次通过 | 38 个非攻击输入 × 32 类变体 × 10 轮，加 2 个已知攻击 × 10 轮 |
| 缓存和运行恢复 | 159 项通过 | 80 次初始请求、64 次缓存命中及容量、深拷贝、版本和内容变化、到期、取消、熔断等检查 |
| 记录批次 | 81 项通过 | 0 至 40 条记录的缺口统计，逐项错误输入摘要拒绝 |
| 总计 | 12,420 次通过 | 异常矩阵包含重复运行；不是 12,420 个独立题目或学生样本 |

异常矩阵包含结构错误、额外命令、未知或重复引用、布尔冒充分数、非法置信度、JSON 重复键、非有限数、超大响应、一次修复、供应商错误及错误文本去敏。其 20,900 次 Provider 尝试全部发生在模拟对象内存中，没有 HTTP 费用。

运行恢复还覆盖 40 个并发竞争请求的忙碌拒绝、运行时更换配置的拒绝、取消不缓存结果、取消后恢复、40 个熔断期请求零尝试，以及冷却期结束后的恢复。缓存检查证明本机进程的既有策略，不等于多进程分布式配额验收。两类已知指令攻击也不构成完整安全红队测试。

## 复现

在仓库根目录运行：

```powershell
python -m backend.scripts.ai_offline_qualification --rounds 10
python -m pytest backend/tests -q -p no:cacheprovider
```

在 `frontend` 目录运行：

```powershell
npm test
npm run build
```

离线验收返回 `OFFLINE_SYNTHETIC`，语义准确率认证、学习更新与正式发布门槛始终为 false。非全通过时 CLI 返回非零退出码。详情与后续实际教师核对、真实模型比较见 [校准准备](ai-semantic-calibration.md) 和 [教研核对工作单](ai-reason-review-workbook.md)。
