# 第二轮体验精磨验收（2026-10-07）

延续第一轮的黑白工作台、路由、布局与键盘操作，重点打磨“点词 → 读释义 → 查其他语境 → 回到判断”，以及网络异常恢复。继续使用 React / TypeScript / Vite、FastAPI 与 SQLite，未新增依赖或修改后端业务规则。

## 修复与交互

- **例证分页不清空本句释义**：同一位置翻页时保留当前释义、已展开内容及分页控制，标注正在读取第几页。失败时明确请求页和仍显示的页，提供重试；成功后定位例证区。换词立即隔离旧词资料，不把旧释义暂借给新词。
- **点读定位**：保存新位置后重置释义栏滚动；单列布局自动定位本句释义标题，新增“返回原文字词”。桌面并排布局不强制移动焦点；跳转遵循减少动画偏好。五层语境与完整原文范围标识保留。
- **长文键盘**：原文采用单一 Tab 入口，左右移动字词，上下移动段落，Home / End 移动段首／末；Enter 才查询并保存位置。移动焦点本身不发训练命令。词组超 80 字拒绝提交，跨段重新选择起点，Esc 退出词组选择。
- **请求有期限**：统一 20 秒期限覆盖连接和响应体读取；保留显式取消语义，区分超时、网络错误、不可解析响应和业务错误。请求不会静默重试。浏览器断网状态只是提示，不凭 `navigator.onLine` 阻止本地 API 操作。
- **训练结果未确认**：网络异常、超时、不可解析响应或 5xx 后保留原命令、版本及幂等标识，暂时锁定新训练操作，定位恢复入口。用户点击“核对并重试刚才操作”才重发同一命令；后端幂等收据避免重复执行。未确认状态离页需确认，刷新／关闭有提示。同步锁也阻止同一事件内的重复点击。
- **窄屏真溢出修复**：移除 `body` 的 320px 最小宽度。Windows 320px 视口实际内容宽度为 305px；旧约束会产生整页横向滚动。现在以 `documentElement.clientWidth` 而不是 `innerWidth` 验收。导航自身可横向滚动，不是整页溢出。

- 人为延迟“于”的第 2 页请求：仍有本句义“比”及 1–5 / 41 页码；成功后显示 6–10，焦点进入例证区。第 3 页请求失败仍显示第 2 页，重试后正常进入第 3 页。
- 手机点“取之于蓝”中的“于”显示“从”，焦点进入释义标题，栏内滚动归零；返回原文后 ArrowRight 移到“蓝”不发 POST，Enter 才保存并查“蓝”。超长词组、跨段及 Esc 均没有误发命令。
- **服务器已处理但响应丢失**：先让真实后端处理提示，再丢弃响应。会话版本从 4 到 5、提示级别从 0 到 1。恢复发送相同请求体与幂等标识，版本仍为 5、提示级别仍为 1。未点击前只有一次 POST，所有新训练操作被锁定。
- 延迟提示并在同一事件内连续点击两次，仅发送一次 POST。手机失败后焦点实际进入 `command-recovery-title`，恢复入口可见。
- 浏览器离线／恢复分别显示／移除连接提示，不自动重发操作。真实浏览器持续无响应的释义 GET 在约 20 秒后显示超时，点击“重新加载资料”可恢复。
- 未确认状态取消离页确认后仍在原训练；确认刷新触发 beforeunload 后恢复相同会话，总共只有原始一次 POST，没有自动重放。空白独立浏览器的 320px 建档页无整页溢出，创建请求失败保留输入并显示中文网络提示，没有创建测试档案。
- 减少动画模式页面动画为 `none`；点读及返回操作使用无动画滚动。注入网络故障的预期控制台错误不计为正常流程故障。

## 回归、数据保护与边界

- 前端 19 项通过：原有路由 6 项、传输异常 8 项、Unicode 点读及键盘 5 项；TypeScript 与 Vite 生产构建通过。
- 后端 99 项全量通过，包含训练幂等与版本冲突回归。
- 无数据库迁移、历史快照改写或知识库发布。13 单元的 3,495 条释义仍为待教研审核草稿；完整性不等于正确性或真人认证。
- 待恢复命令只保留在当前页面内存中。刷新只 GET 读取服务器进度，不自动重放，也不承诺跨浏览器恢复未发出的命令。恢复按钮是沿用原标识的显式重试，不是只读查询；若原命令未执行，本次会执行一次。
- 创建档案／新会话无自动重试，本轮没有增加这两类创建操作的服务端幂等接口或跨端草稿。
- 当前仍是本地规则式全栈 Demo。教研审核、ReasoningGraph、真实模型 Provider、账号权限与生产持久化继续按总指南推进；无鉴权教研接口不能暴露公网。
