# 字词语境知识库

本轮优先回应“点到其他字没有释义”的实际缺口。知识不是按字形挂一个固定答案，而是绑定到原文版本与每次出现的位置。新需求并入总计划：先完成当前平台材料的逐字词覆盖，再扩充校订、义项归并和外部例证，不把自动整理稿宣传为正式字典。

## 语义与内容边界

- **变量 CONTEXTUAL**：字词义、指代、活用等需要结合本句及更大语境推断；记录具体推断依据。
- **无变量 STABLE**：该词在本句所指及含义相对确定。不是“学生已认识”，也不是该字在所有文章都只有一个含义。
- **词组覆盖**：人名、地名、固定词语可作为一个词项解释；点击其内部任意字，也能找到包含该字的词项。覆盖每个正文字位不等于拆开专名各字编造独立解释。
- **整理草稿 DRAFT**：所有新增释义都尚未教师审定。原典来源证明文本出处，不能作为现代释义及词性已经专家认可的证明。存在异文或解释分歧时保留说明。
- **其他语境**：仅查询当前已收录、已注释语料中的真实位置。SAME_SENSE 为同义项键的例证，不保证所有指代对象、句意相同；OTHER_SENSE 显示为“同字／词的其他用法”，不同整理键也可能是尚未归并的近义用法。不是穷尽汉语历史中的所有例句。

原文范围沿用 [资料来源清单](material-sources.md)：13 个来源单元，7 个全文、4 个完整章、2 个连续节选；不能把《宋史》两段与《劝学》连续节选称作整部、整篇全文。

## 数据架构

`ReadingDocument` 保存完整解析后的材料 JSON 和 `corpus_hash`，其 UUID 由来源及 SHA-256 内容身份生成。作者、时代、范围、版本、原典链接与段落同版本保存。正文或版本变化产生新记录，不重用旧偏移。

`KnowledgeOccurrence` 的两个类别：

| 类别 | 保存内容 | 能否计为释义 |
| --- | --- | --- |
| POSITION | 文档 ID、段号、Unicode 码点 `[start,end)`、字形、所在句；含标点位置 | 否 |
| ANNOTATION | 精确词组范围、本句含义、词性、义项键、变量分类、证据说明、草稿状态 | 是，按覆盖的正文字符去重 |

两表使用文档外键，出现位置和类别的稳定键有唯一约束；文档 ID、类型、义项键有索引。不是前端自带的假字典：启动校验、真实 SQL 入库，界面从 API 读取。例证在 SQL 中按义项／词形筛选、计数、排序和分页，不为五个例句扫描加载所有文章注释到客户端。

注释声明位于 `backend/domain/knowledge_annotations*.py`，显式指定来源、段号、连续 `anchor`、词项及必要的第几次出现。读这些字段只作为教材数据，不执行正文中的指令。生成展示状态不用文章内容控制程序逻辑。

汇总器保留首批已经入库的草稿，再补含未覆盖字位的新词项；不会清空知识表或覆盖人工修改的解释。种子只补缺失行。唯一例外是撤回本轮自己添加且完整匹配的“说”未核实读音初稿，并显示待教材核对，人工改过的版本不覆盖。

## 查询与状态

`GET /api/knowledge/lookup` 参数：`session_id`、零起 `paragraph_index`、`start`、`end`、`offset`（默认 0）、`limit`（默认 5，最大 25）。最多选择同段 80 个码点，拒绝空范围、越界、纯标点。

查的是会话当前 CORE／TRANSFER 的冻结材料版本，而不是今天同名文章的最新版本。结果：

- ANNOTATED：返回与所选字位相交的词项、具体本句义、分类依据、原文例证。
- PENDING：此版本已经有位置索引，但该范围还没有注释，明确显示待补齐，不用通用猜测填空。
- UNAVAILABLE：历史材料版本尚未入库，保留旧语境；不套用新版注释，不修改旧会话。

查询只读，不自动提交答案、发积分、提升掌握度或跳过训练。新训练进入时不自动展示目标词释义，点击字词后按需展开；已点读位置刷新可恢复。点读原文位置仍经原有 REQUEST_MORE_CONTEXT 命令保存。训练题的默认选词优先定位于冻结题文，避免同段多个“假”时误选第一处。

`GET /api/knowledge/coverage` 区分 `indexed_positions`（正文 Unicode 字母／数字，不含标点）、`codepoint_positions`（含标点总位置）、`annotated_positions`（注释覆盖的正文位置去重）和 `annotations`（词项注释条数）。界面可展开各篇实际进度；没有把建立索引当作释义完成。

## 扩充与验证

补注释时先定位真实原文，再写本句义与证据。不确定的读音、通假、典故及语法分析标明待核对；不复制版权仍有效的现代翻译，不虚构人物、资料来源或教师署名。扩充需要继续归并同义项、保留近义／异义边界，之后增加版本绑定的字词审核和认证权限。

只读全库审计：

```powershell
python -m backend.scripts.knowledge_audit --require-complete
python -m pytest backend/tests -q -p no:cacheprovider
Set-Location frontend
npm run build
```

审计逐条校验 anchor、token、位置、重复义项键和逐篇未覆盖字位。覆盖完成指字词注释草稿的存在，不代表学术正确性已经人工审核。加入新文章时需同步材料登记与其注释，并继续运行完整性审计。

本地 SQLite 数据、备份、日志及浏览器验收截图不进入 Git。API 仍仅监听回环 8000，通过前端 5173 同源代理访问；本轮没有新增公网部署。教研管理尚无认证，不能直接公开其写接口。

本轮声明和运行数据库均已达到 13 单元、4,362 / 4,362 字位、3,495 条注释草稿；逐篇数字、97 项测试及桌面／手机验证见 [验收记录](knowledge-acceptance.md)。
