# 能力档案和学习队列验收

日期 2026-10-07。融合方案 C 的技术闭环已实现：学习报告展示正式能力依据与独立试测参考，首页支持明确选择练习方向、生成持久队列和进入冻结训练。当前 48 道候选题仍待真实教研审核，正式测评未开放；运行课程尚无有效能力标定，实际推荐为空并说明缺口，旧课程入口仍可练习。

## 能力依据

六维采用字词、句式、语境、篇章、翻译和独立迁移。只读画像从冻结正式试卷及不可变结果重建，不新建可任意改写的主等级表。正式依据必须满足真实题目审核、署名、四维三档覆盖和来源限制。PILOT 不填正式能力；没有合格观测使用 null，而不是零分。翻译和迁移仍无合格测量，保持待评估。

优先采用最新合法且充分的正式结果；较新的不足样本结果不会清除已有有效等级和来源。没有充分结果时可以显示最近合法不足结果的实际样本，未达到每维最低有效作答量的分数不展示。结果时间、题库版本、评分版本和最近 20 条来源历史可查，不静默重算旧结果。

## 队列与内容门槛

练习方向与正式等级分离。可选正式建议或无正式建议时从基础起步，也可明确选择 L1、L2、L3。按实际可用课程生成至多一项主线、一项补强、一项挑战；补强只使用有足够正式样本的薄弱维度。课程不足时返回缺口，不编造补强、复习理由或任务比例。

新推荐只采用已发布、通过当前内容版本审核并具有有效能力标定的课程。FULL、CHAPTER、EXCERPT 和 PROMPT 分开显示，通篇阅读不能使用节选冒充全文。已完成材料不在新队列中无理由重复推荐。

计划、当前指针、稳定任务和幂等收据单独持久化。刷新和读取不生成记录；用户明确提交后，同起点、任务和缺口不变则复用当前计划，包括空计划。同一任务唯一关联训练，完成状态只来自该关联会话。跨教材年级的能力推荐由专用入口开始，不放宽旧练习接口的年级规则。

未开始任务遇到课程、审核或标定版本变化会标为暂不可用。已开始且关联匹配的训练优先恢复原冻结快照，即使课程后来下架也可继续或回看；不会再次创建会话。并发更新失败回滚计划或会话，不留下孤立数据。

## 接口和迁移

| 接口 | 行为 |
| --- | --- |
| GET /api/v1/profiles/{id}/ability | 正式投影、独立试测参考、六维样本和来源历史，只读 |
| GET /api/v1/profiles/{id}/recommendations | 已有计划或 null，读取当前关联状态，不写库 |
| POST /api/v1/profiles/{id}/recommendations | practice_level 可为 null 或 L1–L3，必填 Idempotency-Key |
| POST /api/v1/profiles/{id}/recommendations/{task_id}/start | 空对象请求，必填 Idempotency-Key，返回唯一关联训练 |
| GET /api/v1/admin/lessons/{id}/ability | 标定版本、绑定内容摘要、当前摘要、valid_for_content |
| PATCH /api/v1/admin/lessons/{id}/ability | 同时提交 expected_version 和 GET 所见 expected_content_version |

迁移 v4 为 lesson_abilities 增加可空的 12 位 content_version。旧记录不自动绑定新版本或补造审核。状态冲突与内容冲突分别拒绝写入；页面要求重新读取、由实际教研确认。登录与权限仍暂缓，profile ID 校验不等于身份认证，管理接口不能公开暴露。
