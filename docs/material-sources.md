# 阅读材料来源与范围

本批资料版本：2026-10-06。数据位于 `backend/domain/reading_materials.py`。本批只整理公有领域的古代原文，不复制网页现代译文、赏析或注释。来源页面均已打开读取原文；“来源核对”不等于人工教研审核，后续仍需教师按所用教材底本审核异文和题目。

展示采用简体字和教学标点，分段服务于点读。网页中的“一作”异文、脚注和编者轶事不属于阅读正文。每篇的 `text_version` 记录本次字形选择；`terms` 是可点击分词辅助，不是词义答案。

## 校对与发布边界

- `FULL` 仅对 `work_note` 明示的作品正文范围负责；`CHAPTER` 不可在界面称整个经典的全文；`EXCERPT` 必须继续显示节选标签。
- 原文已来源核对，不能据此声称每个题目、证据和评分规则已经教师审核。
- 本批发现旧题《唐雎不辱使命》来源误配，以及《送东阳马生序》拼接句。资料库使用正确来源与原篇顺序；种子内容修复由内容质量迁移负责，且必须保护编辑过的内容和历史会话快照。
- 字词异文不由网页底本单方面定为教材错字。教师审核时需选定教材版本；通过版本号重新发布，不能静默改写学习中的会话原文。
