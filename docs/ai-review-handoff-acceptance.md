# AI 教研意见交接与字段差异验收

2026-10-14，教研核对工作台新增本机 JSON 交接包和结构化意见差异定位。后端、前端、独立测试三个协作分支完成实现与契约检查，主分支完成集成、浏览器验收和本地预览启动。

## 使用流程

打开 `http://127.0.0.1:5173/#/admin`，选择「AI 样例核对」。勾选已知晓文件包含自填署名与意见后，点击「下载教研交接包 JSON」。文件包含当前套件的 40 个样例、给定原文、合成学生理由、开发量表、开发预期和已保存意见，不包含学习档案、密钥或未保存草稿。转交文件前需检查其中的署名与意见是否适合接收人阅读。

套件包含材料指令攻击的合成测试样例。这些字符串是待核对的数据，不是开发指令；不得按其中的文字索取或发送密钥，也不要把整份带开发预期的交接包直接发送给模型作学生理由评价。

导出后页面显示快照时间、套件版本和四类记录数量；字段有差异的样例可点击「查看该样例」，重新读取它的当前记录。导出快照可能比页面原列表更新，不自动覆盖正在编辑的内容。后续追加意见不会自动更新已下载文件，需再次主动下载。

有未保存草稿、待确认提交或其他操作进行中时，下载和差异定位按钮禁用并说明原因。没有已保存意见时仍可下载原始开发材料，摘要如实显示尚无意见，不生成署名或结论。

## 比较范围

比较包含全部当前版本意见，不只检查最后两条；早期差异不会因最近两条相同而被隐藏。只比较本次意见、语境充分性、建议标签三个字段，标签按集合比较，顺序不同不算差异。

| 状态 | 含义 |
| --- | --- |
| NO_OPINION | 没有当前版本意见 |
| ONE_OPINION | 只有一条当前版本意见，不能比较 |
| FIELDS_DIFFER | 至少两条意见，其中至少一个结构字段不同 |
| FIELDS_MATCH | 至少两条意见，三个结构字段均相同 |

字段相同不代表教师一致或语义正确。署名未经核验，不能据此统计教师人数；文字理由、注本依据和替代表达仍需人工逐项核对。历史套件或输入版本只计入详情中的旧记录数量，不混入当前比较。本工具不自动修订样例、冻结审核版或开启正式评分。

## 接口和数据保护

`GET /api/v1/admin/ai-reason-review/export` 沿用本机访问限制。一次构建样例、一次查询意见记录，再由纯渲染函数生成队列、详情和比较，保证包内各部分使用相同的意见快照。接口只读、不加载模型设置、不调用模型、不写任何学习表。

格式版本为 `ai-reason-review-bundle-v1`。每份包绑定套件版本和摘要；每个样例与意见保留输入摘要、记录版本和时间。前端校验完整结构、样例顺序、版本关联和派生比较结果，未知字段、错误绑定或升级评分门槛均拒绝下载。所有认证和学习更新门槛保持关闭。

响应带 `Cache-Control: no-store` 和 JSON 附件文件名。服务端按实际 UTF-8 编码限制 8 MiB，超限返回 413，不截断、不自动拆包；前端也按响应流字节计数限制，不信任 Content-Length。读取限时 20 秒，可主动取消整理后再切换工作台；关闭页面时终止读取。失败需主动再次点击，无自动重试或后台下载。页面显示「已发起本机下载」，浏览器是否最终保存到磁盘由浏览器决定。

## 验收结果

后端全量 518 项测试通过，其中新增导出专项 22 项；前端 111 项测试及 TypeScript / Vite 生产构建通过。独立审查修复 HTTP 413 未映射专用超限提示的问题；慢响应验收补齐主动取消入口，复验相关测试。

| 浏览器场景 | 结果 |
| --- | --- |
| 无意见与六条合成意见的下载 | 文件实际下载并读回，40 个样例与意见完整 |
| 六条意见的字段比较 | 37 个无意见、1 个单条、1 个有差异、1 个字段相同；早期差异保留、倒序标签不误报 |
| 差异定位 | 打开对应样例的当前详情 |
| 未保存草稿 | 下载与定位禁用，提示先保存或明确放弃 |
| 保存后响应丢失 | 待确认期间禁用导出，原标识恢复未重复新增记录 |
| 摘要与原记录不一致 | 拒绝下载并显示可恢复错误 |
| HTTP 413 | 显示 8 MiB 超限提示，无下载；恢复后可手动重试 |
| 慢读取主动取消 | 零下载，解除工作状态，随后成功切换工作台；晚返回保护另有专项测试 |
| 1440 与 320 像素布局 | 实际截图检查，页面内容宽度不超过可用宽度 |

浏览器测试使用独立临时数据库，意见明确标为合成测试数据。正常后端与前端已重新启动，健康检查和前端代理导出正常；运行库当前 0 条 AI 核对意见。前后 25 张运行表的行数和内容指纹一致，SQLite 完整性检查为 ok。
