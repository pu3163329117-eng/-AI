# AI 推理反馈底座：离线契约阶段

日期：2026-10-08。对应总指南 P0 AI 能力、原始工程规格 T04 的第一部分。用户决定继续保留正式定级门槛；本轮不补造审核人、不把试测改成正式结果，也不启动登录、生产发布或自动调级。

## 已实现

- `backend/ai/providers.py`：厂商无关 `ModelProvider.generate_structured` 协议、版本化请求、统一错误及明确标为模拟的 FakeProvider。默认不配置运行模型。
- `backend/ai/contracts.py`：Teacher、Evaluator、Diagnose 三组输入／输出封闭 Schema，拒绝额外字段、非法命令、布尔冒充分数、未知枚举、空白文本及不一致结果。
- `backend/ai/inputs.py`：从冻结训练快照白名单投影；重新核对 Unicode 码点位置、原文片段、阶段及文本版本。教学输入不含标准答案、提示梯度、档案 ID、积分、迁移资料和完整快照。理由评价需显式提供可信量表，不用“覆盖预设证据”自动编造语义标准。
- `backend/ai/prompts.py`：固定提示版本；原文、学生理由及量表作为独立 JSON 数据消息，而非系统指令。系统提示禁止模型修改状态、积分、掌握值或输出内部思维链。
- `backend/ai/service.py`：已知引用核验、已知答案别名检查、低置信度降级、32 KB 输出上限、重复 JSON 键及非有限数拒绝、一次结构修复上限、四秒总预算、进程内熔断及串行半开探测。
- `backend/ai/evals.py` 与脚本：12 个可重复离线契约／已知攻击模式样例，不读取任何实际学习记录。
- `GET /api/v1/ai/status`：只读上线状态，明确当前真实模型未配置、外部调用关闭、语义反馈不可用、不更新等级或积分；不返回密钥、系统提示或学习内容。

所有结果强制 `may_update_learning=false`。即使测试夹具返回高分，也不接入训练命令、观测写库或正式能力档案。FakeProvider 默认理由评价为 `UNSCORABLE`，默认诊断为 `INSUFFICIENT_DATA`，不是语义 AI。未配置模型、故障或安全失败时只能得到规则式提问模板／不可评分结果；模板与答案别名冲突时可以静默弃答。

## 安全与恢复口径

1. 外部 Provider 必须由调用方显式列入数据政策批准清单；不自动尝试其他厂商。当前并未提供任何真实适配器或调用入口。
2. 明显注入指令在调用前阻断；标准答案别名只在本地检查 Teacher 输出，不送入 Teacher 数据消息。模型自报 `prohibited_answer_leak=false` 不是安全证明。
3. Teacher 只能聚焦已给定的证据；Evaluator 的证据和量表 ID、Diagnose 的观察 ID 必须实际存在。输出仅为建议枚举，不能包含执行状态机命令。
4. 低于 0.65 的评价清除数值分与匹配项，转人工复核；低置信诊断清除精确置信数与诊断结论。该阈值来自初版规格，不代表已实测校准。
5. 只有 `INVALID_OUTPUT` 允许一次结构修复；安全失败、限流和厂商超时不盲目重试。修复不回传无效原始输出或异常文本。等待串行锁也计入总期限。
6. 超时取消异步适配器调用；显式取消继续传播，不伪装为成功。真实适配器以后必须支持协作取消、网络期限和自己的传输体上限，不能在异步方法中做阻塞网络调用。
7. Trace 只含随机 ID、任务、版本、Provider 名、尝试数、耗时、状态及统一错误；不包含学习者 ID、理由、原文、密钥、原始模型响应。Fake 的调用记录仅为测试对象内存，不落盘。

文本别名检查和正则仅覆盖已知模式：不能证明语义改写不会泄漏答案，不能保证所有 Prompt Injection 被阻断，也不能代替真实安全审核。外部适配器、完整审核策略和语义评测未完成前，不开放学生侧生成反馈。

## 尚未完成与下一步

T04 尚未整体完成：没有真实 Provider adapter，也没有通用文本生成、Embedding、Rerank、Moderation 或自动厂商路由；本轮只实现结构化反馈的必要窄接口。

下一轮应先由用户选择 Provider、允许发送的数据范围及成本预算，再实现一个真实适配器。先使用经过人工核验、与实际学生数据隔离的开放理由评测样本，做只读影子评价；核对替代推理、误接受、提示泄漏、低置信度与安全失败后，才决定接入学习页面。必须补齐原规格的语义 Eval 和安全评测，不能把本轮 12 个合成样例当作 V1 质量门槛、Macro-F1 或教学效果证明。

正式能力测评继续等待真实题目审核与边界校准；AI 反馈也不自动解锁正式等级。
