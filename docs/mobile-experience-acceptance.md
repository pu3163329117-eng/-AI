# 手机体验精磨与验收

日期：2026-10-08。范围是现有真实 React / FastAPI 学习流程的布局与导航优化，不重做整站设计，不开放登录、正式定级或公网访问。

## 本轮改动

- 训练行为统计从题目前移到阅读区之后，默认折叠；数据仍由后端快照提供，展开可查看首次与后续表现。
- 提示、暂放、回看等操作收进原生 details“推理工具”，默认折叠；展开仍可操作。320px 小屏先看题文，不被工具面板占满。
- 手机固定快捷栏增加“证据与理由”；三个入口分别定位正文、理由编辑器和题目，并转移焦点。理由标题增加可聚焦锚点。
- 理由输入框获得焦点时收起底部快捷栏，减少输入区遮挡；这是焦点规则，不是软键盘检测。
- 主导航进入深链接及窗口尺寸变化时，只水平滚动当前导航项，不滚动整个文档。新增两项导航回归测试。
- 完成页不再显示无效的推理工具；区域名称关联总结标题，不再引用不存在的题目标题。
- 保留现有黑白风格。使用前端工程 skill 的响应式、焦点管理及回归检查要求完成本轮调整。

## 浏览器实测

使用独立 QA 前端 5174、后端 8001 和模拟模型。正式 5173 / 8000 与已有学习数据库没有用于测试写入，未读取或发送真实 API Key，未执行付费模型调用。

实际跑通：高中建档 → 《岳阳楼记》首次词义判断 → 原文起止字选段 → 保存理由 → 刷新恢复 → 核心规则核验 → 《论语·颜渊》迁移 → 新证据与理由 → 迁移核验 → 完成总结 → 学习报告。

迁移阶段没有带入核心阶段的理由；“克己复礼”单一线索未满足课程的全部预设证据，补选含“克己复礼、为仁由己”的连续原文后完成核验。没有绕过规则。报告显示真实测试记录：完成 1 次训练、20 知行、2 个首次观测阶段；正式能力仍待评估，开放理由仍待复核。

展开推理工具后，暂放、提示、回看均实测可操作；展开训练行为记录后能看到核心与迁移阶段的实际提交次数。

## 测试环境修复

原隔离 QA 服务使用内存 SQLite + StaticPool，并发页面请求共用一个连接，出现 SQLite API misuse。改用独立临时文件数据库和默认连接池，重新建立测试档案并跑通上述闭环及布局矩阵。该修改仅在 `backend/scripts/ai_preview_browser_qa.py`，不是正式数据库迁移；服务退出时关闭连接并清理自身临时目录。

验收收尾已停止 8001 / 5174，并清理专用临时数据库及失败启动留下的空目录。正式 8000 健康检查正常，5173 返回 HTTP 200。Windows 强制结束进程可能绕过 finally，因此本次另行检查并清理了临时目录；截图与本文件保留。

## 尚未验收的边界

- 未保存理由的站内离开确认：内置浏览器弹窗阻塞了自动鼠标操作，未证明取消后恢复和确认放弃两条分支。本轮不将此项标为通过；需要解除测试弹窗后单独复验。
- 真机 Safari / Android 浏览器的软键盘、输入法组合、触摸选词及横竖屏安全区仍需真机验收。桌面响应式尺寸模拟不能替代真机结论。
- 三个手机快捷按钮至少 44px 高；小屏仍需纵向滚动，不承诺所有内容都放入首屏。
- AI 语义质量、教师量表审核和正式等级标定不属于本轮。下一阶段再进行固定样例、教师预期与模型反馈的对照。
