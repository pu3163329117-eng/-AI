# 本机理由反馈：影子试用

日期：2026-10-08。承接真实 DeepSeek 连接验证，开发手动试用流程，不将一次接口成功升级为语义质量认证。登录和权限仍按用户决定暂缓，因此付费试用只接受本机访问，不开放内网／公网正式学生调用。

## 怎样使用

打开 `http://127.0.0.1:5173/`，进入训练：

1. 先提交本阶段首次词义判断，保留追加辅助前的首次表现。
2. 在原文选择证据，填写理由并保存。
3. 在“理由反馈”区勾选本次最小范围发送许可，点击“请求理由反馈（试用）”。没有许可、理由未保存、有未保存改动或训练命令结果待恢复时不能请求。
4. 查看候选意见、模型引用的原文、被认为具备的表达要素和下一步建议。意见可能错误，需自己或老师核对，不是“已复核”。

内网同事仍可进行原有训练，但此本机试用不能作为无认证的共享付费入口。已保留当前 Key，无需重新填写。不自动调用、不自动重试；模型调用可能产生费用。

## 架构和契约

`POST /api/v1/ai/sessions/{session_id}/reason-feedback`

```json
{"expected_state_version": 3, "send_minimal_data": true}
```

只接受上述字段，不能从客户端提交替换理由、评分量表、原文或标准答案。后端从数据库冻结快照读取当前图，核对阶段／文本版本／目标词／码点证据位置。当前题文及所选证据、保存的理由与结论、试用表达量表被投影到模型契约，昵称、会话／档案 ID、未来迁移内容、标准答案、积分和历史记录不发送。模型不能执行训练命令。

当前量表为 `reason-preview-v1`，只用于原文引用、关系表达与推断边界的试用比较，**未经教师审定**。不是课程专属标准答案量表，不能凭它认证词义或正式能力。返回中的 `rubric_review_status=NOT_VERIFIED`、`mode=SHADOW_PREVIEW`、`may_update_learning=false` 固定；数值分数、置信度和模型原始标签不交给页面。页面意见／建议来自经验证的标签对应固定文案，不是模型生成的自由长评，也不宣称辨析已穷尽。

原文引用必须来自所发证据 ID；虚构引用和异常 JSON 最多修复一次，失败则不显示候选。低置信度降为无法可靠复核。常见个人信息／指令模式在发送前阻断；正则并不能保证识别所有个人信息，学生理由中仍不能填写私密资料。

## 一致性、费用和失败

- 本机进程共享一个 Provider、配额和熔断器，而不是每个 HTTP 请求新建无限额度实例。最多 5 次 HTTP／分钟、20 次／小时，每次最多 768 输出 tokens；包含修复／失败。不是账户人民币预算。
- 本机最多一个未完成的试用请求；并发返回 `AI_FEEDBACK_BUSY`，不额外调用。4 秒模型总期限，最多一次格式修复。
- 以会话、进度版本、试用量表版本及投影内容的摘要绑定结果，进程内缓存最多 64 条、保留 10 分钟，成功和降级都缓存。同一条重读不付费重放。缓存不持久化，过期、重启、配置／进度改变后再次手动请求可能重新收费。
- 训练版本在请求前和返回前都检查。生成期间版本改变返回 `AI_FEEDBACK_STALE`，不把旧阶段意见展示在新阶段。
- 前端绑定阶段／材料／进度版本；修改理由隐藏旧意见，保存、点读导致版本改变或进入迁移时重置面板与勾选许可。刷新只读取配置和训练，不自动重放请求，也不承诺恢复旧候选。
- 超时、限流、结构错误、安全阻断及供应商异常均如实降级；不显示固定模板为“模型复核成功”。浏览器取消不保证供应商免计费。
- 无新增数据库表／迁移；不写训练快照、理由审核状态、观测、积分、推荐、等级、命令回执或审核记录。首次判断必须已记录，因此额外辅助不会被写成独立首次表现。
- 本机／Origin 检查不等于生产鉴权。API 状态中 `student_feedback_enabled=false`、`external_calls_enabled=false` 仍指正式发布及自动调度未开放；`local_preview_available` 和 `local_preview_external_calls_enabled` 单独描述本机自愿试用。

## 验证记录

自动化使用隔离数据库与 MockTransport，不读取实际 Key、不发送真实学习数据或付费调用。新 API 测试覆盖最小投影、无写入、首次判断与版本门槛、严格许可、拒绝客户端量表、Origin／Host、本机缓存与并发、配置失败、敏感输入、限流、虚构引用和超时。

本轮最终后端 411 项、前端 86 项回归通过，TypeScript 与生产构建通过。Windows 沙箱曾阻止测试子进程和临时目录读取，转为明确隔离目录运行后通过，没有修改产品权限策略。真实 API 已重启，8000 直连和 5173 代理的本机试用状态均为可用、正式学生发布仍关闭。重启前后运行数据库完整性为 `ok`，24 张表的原有行整体指纹一致，没有改写已有学习数据。本轮浏览器／API 自动化没有新增真实模型费用。

实际浏览器通过独立 5174 QA 前端和 8001 内存服务完成：建档、首次判断、选取“为执经讲解”、保存理由、请求候选、重读缓存、修改理由后隐藏旧候选与保存后重置。QA 服务用模拟响应，不是 DeepSeek 语义质量验收。320 和 1440 像素宽度实测页面滚动宽度等于视口可用宽度，无横向溢出；截图保存在本机 `output/playwright/reason-feedback-320.png` 与 `reason-feedback-1440.png`，不上传学习数据。

浏览器 QA 命令 `python -m backend.scripts.ai_preview_browser_qa` 仅启动隔离内存模拟服务，不用于生产部署；退出即丢弃其测试档案。真实本地训练服务继续使用 8000／5173。
