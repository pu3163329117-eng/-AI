## 真实浏览器验收

使用独立验收草稿与隔离浏览器档案，不为正式课程填写教师署名。

1. 教研界面显示出处、材料范围、作者、时代、原文链接与资料版本；展示原文不代表人工审核。
2. 审核人未填写时不能审核；有未保存修改时不能审核或发布。
3. 保存 → 填写验收署名 → 审核 → 发布成功，界面与 API 状态一致。
4. 实质修改已发布验收关卡 → 保存 → DRAFT / STALE，发布按钮禁用。该验收关卡结束时保持草稿，不进入普通学习目录。
5. JSON 语法错误及只填写单阶段均显示中文提示，不写入错误数据；恢复数据库中的编辑稿后可继续保存。
6. 工作台在 1440 / 1024 / 768 / 390 像素宽度下无页面横向溢出；手机审核输入为 16px，按钮及来源链接具有至少 44px 高度。
7. 未建档时返回今日训练、点击能力地图均显示建档引导，不再只显示导航栏的空白正文。
8. 独立学习档案可正常建档、从首页进入真实训练；新资料显示宋史连续两段及其范围、时代与版本，不把史书节选标成整传全文。
9. 新资料点读“质问”后，服务端保存选择；刷新恢复同份快照及冻结版本，没有虚构未审核课程的署名。
10. 模拟另一页面改稿后，列表刷新不偷换表单所读版本；旧页面审核返回版本冲突和中文重读提示。实际重新读取后审核、发布成功，验收关卡再次退回草稿。
11. 模拟课程详情读取 503，原课程表单隐藏、保存按钮移除，展示读取失败提示；没有把旧表单提交到新课程。
