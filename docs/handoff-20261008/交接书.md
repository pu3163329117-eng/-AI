## 6. 核心契约，不得回退

### 状态、重试与版本

训练命令：`POST /api/v1/training/sessions/{id}/commands`，要求 `Idempotency-Key`、`expected_state_version`、`type`、`payload`。CAS、事件、首答观测、收据和积分在同一事务内；发生冲突不能覆盖已确认状态。

结果未知时只能明确沿用原幂等标识恢复，不能生成新标识盲重发。刷新是 GET 恢复，不自动重放命令。保留 20 秒请求期限、运行时契约、页面错误边界及未保存离页保护。

原文位置使用 Unicode 码点（JS `Array.from`），段索引从 0 开始、范围 `[start,end)`、同段最多 80 码点、标点保留。历史会话绑定原文版本，不能用新版偏移解释旧位置。改稿后当前审核、标定失效，已有冻结会话仍可继续。

试测选项按稳定 ID 判分，卷内排序冻结，交卷前接口不返回答案或解析。旧训练仍按实际选项文本契约处理，不直接将评测 ID 逻辑套入旧训练。

### 学习行为与能力

新训练 CORE 和 TRANSFER 各自冻结首次判断与当时辅助。读原文、展开五层语境、自己选择证据不算辅助；释义、提示、预设证据、规则回执、判断反馈分别计 `WORD_MEANING`、`HINT`、`PRESET_EVIDENCE`、`RULE_CHECK`、`FEEDBACK`。

新训练需先确认辅助记录，再挂载字词解释组件或请求解释；每阶段一次授权，迁移重新授权。响应丢失时不得提前泄露解释。首答可在证据与理由前提交，但不直接给完成积分；后续通过不覆盖首答错误。

旧会话缺少字段时显示 UNKNOWN，不猜测回填。训练 API 仍包含答案性字段，外部资料也无法控制，因此 `NONE_RECORDED` 只能称“首次判断前未记录辅助”，不能宣称独立掌握。

报告按真实阶段样本分母汇总，未知不纳入首答率；零分母为 null，不是零分。汇总全部观测、来源列表最近 50 条；北京时间趋势区分首答与后续核验日期，不将辅助组差异解释为因果效果。

正式能力来自合格正式结果，不来自 PILOT、积分、完成数量或 D 的学习记录。未测维度为 null。较新的不足结果不冲掉旧有效依据；六维中的翻译与迁移需相应合格测量才能更新。
