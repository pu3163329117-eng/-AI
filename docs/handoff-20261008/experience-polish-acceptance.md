# 阶段体验精磨验收（2026-10-07）

本轮针对导航、排版、阅读工作台、交互反馈和手机布局进行实际代码改造；保持 React / TypeScript / Vite、FastAPI 和 SQLite 架构，没有增加前端依赖。独立浏览器使用“体验精磨验收”档案测试，不修改用户档案或保存、审核、发布教研课程。

## 已实施

- 主导航采用真实 hash 链接：`#/home`、`#/skills`、`#/practice`、`#/review`、`#/profile`、`#/report`、`#/admin`。训练地址绑定会话 UUID，刷新保留具体页面及会话；浏览器前进、后退支持恢复。非法地址安全返回首页或复习，失效会话提供重读、返回入口。
- 教研未保存表单增加全站离页和浏览器返回确认，以及原生刷新／关闭提示。保存、审核或训练命令进行中拒绝离页，避免响应覆盖另一页面中的学习状态。未保存草稿不是持久化草稿；确认放弃后不再保留。
- 黑白阅读工作台统一标题尺寸、页宽、留白和点击区域；主导航、账户和主要操作至少 44px 高。窄屏导航可横向滚动，不把页面横向撑宽。
- 当前题文、选项与反馈置于正文前方；完整正文和词义侧栏分别限高滚动，保留全部原文和五层语境。桌面证据板随阅读保持可见；窄屏证据板先于题目展示，DOM 与视觉顺序一致。
- 手机底部固定“阅读原文／回到题目”快捷栏，页面预留末尾空间。跳转同时移动焦点；进入迁移和总结也定位到新任务或总结。
- 答案采用原生 radio，支持方向键；专项分类补齐 tab / tabpanel 关系、方向键和 Home / End 操作。异步分类请求只采用最后选择的结果，避免旧请求覆盖当前内容。
- 增加 200ms 页面过渡、选项反馈、按压反馈和具体操作的进行中提示；遵循减少动画偏好，不引入滚动劫持。
- 能力页取消完成关卡数推算分数，改为真实判断事件统计，并显示样本量及小样本限制。新事件保存当时的目标词及阶段；旧事件未记录目标词时归为“历史判断·未记录目标词”，不从当前快照猜测或追写历史数据。

## 实测结果

七个主导航页面逐一在下列视口检查，所有页面有可见主内容、地址对应正确、未出现文档横向溢出。训练展开“于”的 41 处其他语境，不挤动题目位置（允许浏览器浮点测量误差）。

专项页刷新保留 `#/practice`；前进、后退切换 `#/admin` / `#/practice` 正常。训练深链接刷新恢复同一会话。不同会话间前进、后退后没有沿用上一会话的未提交选项。

另模拟会话读取延迟并立即返回：原会话重新显示，晚到的失效会话结果不覆盖界面，加载指示不会卡住。

未保存的新建表单只输入临时题目，不提交：分别取消导航确认、返回确认、刷新提示后，地址及输入仍在；确认离开后正常返回首页。测试捕获两个 confirm 和一个 beforeunload。

原生 radio 方向键可选择下一答案；分类 ArrowRight / End 可切换。测试浏览器人为延迟不同 GET 分类响应，最后显示推理考点，没有被旧的主题或教材请求覆盖。减少动画偏好下页面 animationName 为 `none`。

测试档案真实跑通劝学核心题选证据 → 判断 → 送东阳迁移 → 完成总结，焦点落在 `summary-title`。能力页实际显示“词义判断·假”、2 次判断、100%，并标注样本较少，不将其宣称为完整能力测评。手机快捷操作焦点分别落在 `fulltext-title`、`training-question`；底部栏位置等于 900px 视口底部。

修复验收中发现的训练任务与阅读器重复 React key；最终正常训练流程没有再出现该警告。失效会话测试的预期 404 不等于页面空白。

本地截图位于 `output/playwright/refined-*.png`，已人工查看桌面训练、手机训练、专项练习及真实能力页；截图和测试浏览器档案不上传仓库。
