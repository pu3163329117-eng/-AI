# 首次判断与学习行为回流验收

2026-10-08 完成融合计划 D 的学习行为闭环。新训练分别保留首次词义判断、当时已记录的辅助、后续证据规则核验和重答完成；报告提供阶段汇总、北京时间趋势与来源回看。它不构成闭卷能力测量，不更新正式等级。48 道当前候选题仍待真实教研审核，正式测评未开放。

## 行为口径

| 行为 | 新训练记录 |
| --- | --- |
| 阅读原文或展开词句段篇时代语境 | 不算辅助 |
| 自己选择原文证据 | 选择本身不算辅助 |
| 保存证据后收到覆盖规则回执 | RULE_CHECK 辅助 |
| 查看字词本句义、词性、推断依据和相关释义 | WORD_MEANING 辅助，确认后展示 |
| 请求提示 | HINT 辅助 |
| 使用旧预设证据命令或暂放后回看预设线索 | PRESET_EVIDENCE 辅助 |
| 收到词义判断反馈 | FEEDBACK 辅助，仅影响之后的提交分类 |

字词解释按每阶段一次授权，不承诺逐词浏览次数统计。进入迁移阶段重新等待授权；核心阶段的辅助不污染迁移阶段。旧会话不新增跟踪字段，继续显示辅助情况未知，不倒推出首次答案。

新会话允许先提交首次词义选择，再补充证据和至少 5 字的理由。选择正确但证据不足不算完成规则核验；首答不直接发积分。后续通过仍保留首次错误或首次证据不足。理由保持 UNREVIEWED，不把字数、非空理由或覆盖预设词组当作语义正确。

训练模式的旧接口会返回课程答案性字段，阅读者也可能使用外部资料。因此“首次未记录辅助”仅表示平台没有记录上述辅助，不称为真正独立作答。两类样本不是随机对照，不能从正确率差异推断提示的因果效果。

## 数据与事务

StageObservation 保存首次阶段观测，按 session_id 与 stage 唯一，并唯一关联实际 training.first_attempt_recorded 事件。记录首次答案、选项规则结果、证据覆盖、当时辅助列表、材料来源和版本。后续核验与尝试数从实际训练事件重建，不覆盖首答。

命令的状态 CAS、事件、首答观测、幂等收据和原积分更新共用事务；失败一起回滚。事件序号采用现有最大值后追加，不用状态版本充当多事件序号。重复命令沿用同一收据，重复 GET 不增加样本。每阶段已核验后拒绝重复作答；旧客户端兼容路径保留。

GET `/api/v1/profiles/{id}/observations/report` 为只读报告。汇总与趋势使用全部观测，最近来源仅展示 50 条；分母是有新首答观测的阶段。CORE 与 TRANSFER 分别汇总。旧未知不纳入首次比例，零分母为 null，页面显示暂无样本。首次日期与后续重答完成日期分别使用实际事件时间，统一按 UTC+08:00；原时间戳保留 UTC。旧核验事件缺失显示记录不完整，不将缺失当成答错或未完成事实。

报告不修改正式能力档案、推荐门槛、课程标定、翻译能力或积分。完成积分仍来自原 COMPLETE_SESSION 规则。profile ID 不是身份认证，管理接口仍不得公开暴露。
