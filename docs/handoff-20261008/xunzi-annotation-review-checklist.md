## 依据与签审方式

各表“依据”使用以下缩写；原典与注释证据须分别登记：

- A：[荀子·劝学篇古代原文](https://zh.wikisource.org/wiki/荀子/勸學篇)，已打开核对篇首连续段及节选后的继续正文。
- B：同一页面夹注的历史注释；核验时应进一步登记古注作者、所用版本与页码，当前不凭网页自动署名某位注家。其“绝，过”“能，善”“跪，足也”等可作待复核线索，不等于网页原典已替程序草稿背书。
- C：`knowledge_annotations_classics.py` 与 `knowledge_annotations_xunzi.py` 的原创整理草稿。代码中的 reasoning 不算独立权威出处。
- T：实际选定教材／注本的版本、页码及审核记录，尚未登记。正式使用前补齐；异文和句法分歧优先对照该底本。

每个 anchor 都是当前正文精确连续子串。审核须逐处定位后查看词项 `start/end`、`sense_key`、释义、词性及 reasoning；同字在不同位置不能一键全改同义。复合词、专名整体释义，不能为了覆盖率硬拆兰槐、蒙鸠、射干等名词。

“变量”指本句是否需要随语境辨义：CONTEXTUAL／变量与 STABLE／本句相对确定，均不表示学习者认识或不认识。表中变量点是需要核验的候选判断，不自动改变草稿字段。每行审核补实际审核人、日期、所据 T、结论及修改后的新版本；空白不算通过。

## 重点暂缓与验收

参省细分、化道、神之听之、射干／兰槐现代对应、其渐之滫句法、柱训、驾程、圣心备焉等均有版本或细分空间。在真实教师选定注本前，不以这些争议细节出“只能这样解释”的正式题；候选库只选相对清楚且上下文证据足够的内容。

人工验收必须核对：

1. 全部 anchor 仍位于被审核的文本版本；章节、标点及字形差异逐项登记。
2. 同字异处：于来源／比较／处所／专名，而修饰／承接／并列／转折，之代词／结构标记，生出生／天性／出现／生长，一数量／一样／专一。
3. 每处 meaning、词性、变量与 reasoning 相互一致；“本句相对确定”不等于这个字只有一个义项。
4. 古注／教材依据和项目原创推断清楚分开；未核定读音、单位、物种、作者署名不补造。
5. 审核结论含真实人、时间、版本及变更记录；学习会话继续用冻结旧文，不以新节选、注释或审批覆盖历史。

程序可验证精确定位、重复与字位覆盖；不能代替训诂裁决或教师审批。本文件是一份待核清单，不是内容质量通过证明。
