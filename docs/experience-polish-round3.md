# 第三轮体验精磨：异常数据与渲染恢复（2026-10-07）

继续第一、二轮的黑白阅读工作台，不改技术栈，不增加依赖。本轮解决合法 JSON 结构错误造成的白屏，并完善建档进行中状态与页面出错后的恢复入口。

## 可复现问题与修复

独立验收会话中，将一次真实字词 lookup 响应的 `annotations` 改为 `null`（只修改浏览器接收的数据，不改库）。旧页面执行 `.map` 后整个 React 根节点为空，主内容数量为 0。

新增 `contracts.ts`：接口客户端在写入组件状态前验证响应信封、数组成员及实际渲染的嵌套字段。覆盖档案、课程、训练、复习、报告、成就、专项、教研、知识库。错误响应抛出 `INVALID_RESPONSE`，不把错误转换为成功的空目录、零能力或空档案。

校验允许服务端新增字段，历史可选字段缺省仍有效；不强制给旧训练补教学署名、读音或知识库资料，不修改冻结快照。未知接口契约需要显式登记；本轮是界面数据形状保护，不替代服务端领域校验、鉴权或教材审核。

新增 `RenderBoundary`：页面级渲染错误显示黑白恢复页，保留主导航；切换页面后重新建立边界。应用级边界保护 App 的 React 渲染故障。提示未保存输入可能丢失，提供重新读取入口，不清理 localStorage、不删除数据库、不自动重发训练命令。边界不承诺捕获 JS 文件下载失败、事件回调或任意异步异常。

建档表单在请求期间锁定姓名与学段；姓名有显式文本类型、必填语义与可见键盘焦点；学段标签至少 44px 高。契约错误保留姓名和学段，不把空服务端对象写成档案入口。关卡目录用中文错误信息区分读取失败和真正无关卡。

## 实际验收

使用独立浏览器的“体验精磨验收”档案，不使用用户档案；空白浏览器建档测试只模拟响应，未创建真实档案或发布教研课程。

- **真实接口兼容性**：13 个只读响应检查全部通过，包括当前训练、档案、目录、复习、错题、报告、任务、成就、专项、教研列表／详情、知识库覆盖与释义。真实训练命令响应也通过校验。
- **异常注释**：改为 `null` 后，原文、题目和导航保留；只在释义区显示中文重读入口，点击后恢复。没有触发整页兜底或清空学习数据。
- **异常训练收据**：真实后端先执行提示，再把浏览器收到的 `session.choices` 改为 `null`。前端保留旧有效会话和原请求标识，显式恢复后版本只从 12 到 13；两次 POST 使用同一标识和请求体，没有再次执行。
- **渲染兜底**：浏览器临时注入会抛异常的字词组件；恢复页保留导航，返回今日训练正常，重新读取原会话正常。整个恢复流程 0 次 POST。注入仅在浏览器路由中，源码中没有测试故障开关。
- **应用兜底与焦点**：另注入 App 渲染故障，320px 恢复页无溢出、档案 ID 未改变，重新读取恢复原训练。页面与应用恢复标题均实际获得焦点；按钮键盘焦点仍可见。
- **新建档案**：390px 屏宽下，延迟请求时姓名、学段均锁定；模拟 `{profile:{}}` 后有中文错误、输入保留、localStorage 无档案 ID，只发送一次请求。学段标签高度均不小于 44px。
- **目录错误**：结构不完整的目录成员显示读取失败而非“无关卡”；重读后恢复实际课程。

正常七页及训练分别在 1440 / 820 / 390 / 320px 检查；有可见内容、无整页横向溢出、没有错误触发兜底。渲染恢复页在相同四种屏宽检查，无溢出、操作按钮不小于 44px，并已人工检查电脑与手机截图。继续保留第二轮点读、分页、请求期限与幂等恢复。
