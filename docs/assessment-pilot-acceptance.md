# 能力分级融合首轮：内容准备与四维试测验收

日期：2026-10-07。交付范围为融合方案 A / B 的技术基础和本地试测闭环，不代表正式评测已具备教研认证。当前候选池 48 题，真实已审题 0 道；正式入口关闭。

## 本轮可用功能

- 学习者进入“能力试测”，可先完成四道轻自评，再创建 24 题试测；自评不计入客观分。
- 四维分别为字词、句式、语境、篇章，每维 6 题，L1 / L2 / L3 各 2 题。服务端检查至少 4 个来源，同一来源不超过 6 题；有限次组卷不能满足约束时明确拒绝，不减少题量凑卷。
- 按稳定选项 ID 保存作答，选项展示顺序随机后冻结；试卷、原文范围、题库和评分配置均冻结。刷新不重新抽题、重排或重算旧结果。
- 已保存答案、明确跳过和未处理题分别记录。24 题都已作答或明确跳过后才能交卷；上一题、下一题与保存操作区分，不把尚未保存的选择显示为已保存。
- 交卷后显示四维分数、呈现／作答／跳过／正确样本、充分度原因、相对优势、补强项及逐题解析；翻译和迁移显示待评估。试测始终不产生正式 L1–L3 等级，不改变旧课程入口或积分。
- 全部跳过时综合分与四维分为 null，页面显示待评估，不显示零分能力条；部分未作答时保留实际覆盖说明，不重新加权成完整评测。
- 内容管理增加“课程能力标定”，独立记录 L1–L3、六类专项标签、标定人和依据。任务难度与全文／章／节选分别管理；标定不等于注释或评测题审核。

本地入口：[能力试测](http://127.0.0.1:5173/#/assessment)、[内容管理](http://127.0.0.1:5173/#/admin)。已有档案无需重建；新用户仍先通过原有建档入口进入。未强制替换建档流程，也未接入新推荐队列。

## 架构和数据约束

沿用 React / TypeScript → FastAPI → SQLAlchemy / SQLite。新增独立 assessment 领域、路由和存储模块，不将组卷或判分放到前端。

| 新增数据表 | 职责 |
| --- | --- |
| assessment_question_revisions | 按题目 ID / 版本保存私有候选题，不覆盖已保存题目 |
| assessment_sessions | 档案、模式、冻结试卷、状态版本、作答、自评及保存位置 |
| assessment_receipts | 同会话命令标识、请求摘要及收据，防止重复保存和交卷 |
| assessment_results | 完成后不可变结果，保留题库和评分版本 |
| lesson_abilities | 独立课程标定元数据，乐观并发版本检查 |

本地先行联调曾入库 48 道 v1；最终候选版本为 assessment-pilot-v2，新增 48 道修订而不覆盖 v1。库中 96 条题目版本记录不等于当前有 96 道活跃候选题。当前 48 道候选均为 DRAFT，审核人和时间为空。

服务端交卷前使用公开字段白名单，不返回答案、解析和内部评分权重；交卷后才返回逐题解析。此限制不是考试防作弊或用户身份隔离承诺。源码公开，本地管理接口尚无鉴权，不能作为公网正式考试系统。

评分版本 equal-tier-24-v1：同维度题目等权，四维综合权重为 30% / 25% / 25% / 20%。45 / 75 分和难度层门槛只作为正式模式的待校准建议规则；PILOT 即使全部答对也不定级。充分度是覆盖规则，不是统计置信区间。首次真实试答耗时尚未收集，不承诺 8–10 分钟。

### 恢复、并发与故障

测评命令 SAVE_ANSWER、SKIP_QUESTION、COMPLETE_ASSESSMENT、ABANDON_ASSESSMENT 必须携带 expected_state_version 与 Idempotency-Key。同标识、同请求返回原收据；同标识不同请求和旧状态版本返回冲突，不覆盖已确认结果。

创建时同档案、同模式只有一个活动试卷，重复创建恢复活动试卷，不依赖创建请求的幂等收据。创建响应未知时只读取历史寻找试卷，不自动重发 POST。命令响应未知时暂停写入，用户可沿用页面内原标识及请求明确恢复；未确认请求刷新后不自动重放。重新进入以服务端进度为准。

页面、题目和课程标定编辑有未保存／未确认操作时提示离开风险。课程标定 PATCH 携带 expected_version、实际标定人及依据；并发冲突不自动重试覆盖。当前署名没有关联认证身份。

WENYAN_ASSESSMENT_ENABLED=0 并重启后端可关闭新建入口；既有测评仍可读取、继续和查看结果。不是删除数据库或历史结果的开关。

## 内容准备

内容分支起草 48 题，覆盖现有 13 个阅读单元。题目记录资料版本及 Unicode 连续定位，篇章题只用于完整全文或完整章。《劝学》和《宋史·范仲淹传》继续标为节选，不冒充全文。

48 题的四维三档覆盖及干扰项仍需实际教师核验；《劝学》逐句清单是待核材料，没有据此写入人工审核或自动修订知识库。参见 [候选题库与门槛](assessment-bank-content.md)、[劝学核验清单](xunzi-annotation-review-checklist.md)。

正式题库需满足四维三档每格至少 2 道实际已审题和来源组卷约束；题目审核工作流、真实审核、代表性试答与阈值校准仍待推进。课程能力标定不能解除评测题审核门槛。
