# 独立评测题审核闭环验收

日期：2026-10-08。仓库按用户要求由公开改为私有，GitHub API 复核 `private=true`。本轮补齐教研题目审核工具，不替真实教师审批，不开放公网管理服务。

## 交付

入口：内容管理 → 评测题审核。按四维及草稿/通过/退回筛选和分页，展示连续原文、范围、原典出处、冻结定位、题目身份、稳定选项、正确选项与解析。可保存新稿、人工署名通过/退回、查看修订和审核依据。审核人、依据均由实际核对者输入，不预填真人、不声称身份认证。

API：`GET /api/v1/admin/assessment/questions`、`GET /{question_id}`、`PATCH /{question_id}`、`POST /{question_id}/review`。写入要求 `Idempotency-Key`、整数 `expected_version`、actor 与 note；编辑字段采用白名单，不允许客户端设题目身份、版本、审核元数据。

新增 `AssessmentQuestionHead`、`AssessmentEditorialReceipt` 两张增量表。内容继续追加既有 `AssessmentQuestionRevision`，不原地改写版本。头 CAS、修订和收据同事务；旧版本冲突不覆盖，重复标识返回原收据，跨操作复用标识拒绝。锁冲突与存储服务故障分开处理。

编辑撤销旧审核；来源、原文和定位在此冻结，批准时校验真实来源、文本版本、连续位置及篇章范围。坏来源/过期定位可以退回，不要求错误题先合法才准退回。读取明确给出 `validation_valid` 与 `validation_error`；异常引用仅按原始记录展示，禁止批准和保存，退回后可确认，不陷入无限未知恢复。

新建试卷使用当前修订，并冻结题库修订指纹；种子不覆盖人工头，旧试卷和评分结果不变。REJECTED 退出新 PILOT / FORMAL 候选池。内容审核不是测量校准，正式评分仍是试行规则。

前端保留四态、未保存离页保护、请求期限、严格契约和显式恢复。结果未知时暂停其他写入，sessionStorage 保存原 key 和 body，刷新不自动重放，用户明确恢复同一操作。窄屏选择题目后定位编辑区，编辑标题避开固定导航；选项标识换行，动作至少 44px，键盘及减少动画可用。

## 浏览器验收

使用独立 Playwright CLI 会话；读写审核请求映射至 **8001 隔离数据库**。运行库 8000 不做测试署名。

| 场景 | 结果 |
| --- | --- |
| 1440 / 820 / 390 / 320px | 实际渲染、长标识与正文检查，无横向溢出 |
| 未保存换教研标签 | 原生确认出现，取消后保留修改 |
| PATCH 已提交后断响应 | 隔离库实际增加一次修订，页面暂停其他写入 |
| 未知操作刷新 | 离页保护；刷新后原 key/body 仍保存，不自动写入；显式恢复不增加第二修订 |
| 通过 → 退回 → 再改稿 | 隔离库状态与追加历史一致，改稿变为待审 |
| 历史折叠 | 键盘 Enter 可打开 |
| 列表 500 | 不把异常显示为零题或旧成功列表，重新读取后恢复 |
| 坏来源响应注入 | 警告、批准禁用、退回可确认；精确 mock 子路由后无数据库写入 |

首轮故障注入的匹配器未覆盖 `/review` 子路由，产生了一次额外**隔离库**退回；修正为双星匹配后重测通过。故意中断与 500 产生预期网络控制台错误；完成流程无未捕获页面异常。测试脚本在本机 `frontend/tests/assessment-editorial*.browser.cjs`，未当作默认 Node 测试入口。
